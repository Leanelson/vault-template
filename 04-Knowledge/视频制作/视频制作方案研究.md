# AI视频制作方案研究报告

## 研究目标
找到省算力的视频制作方法，支持批量自动化生产

---

## 方案对比

### 方案1: 云端API（最省本地算力）

| 工具 | 特点 | 成本 | 适用 |
|------|------|------|------|
| **OpenAI Sora** | 文本→视频，质量最高 | $0.5-2/分钟 | 高质量需求 |
| **Runway Gen-2** | 视频生成+编辑 | $0.2-0.5/秒 | 创意视频 |
| **Pika Labs** | 短视频生成 | 免费额度+订阅 | 社交媒体 |
| **HeyGen** | AI数字人 | $24/月起 | 口播视频 |
| **D-ID** | 照片说话 | $5.9/月起 | 简单动画 |

**优势**: 本地零算力消耗，按需付费
**劣势**: API费用，网络依赖

---

### 方案2: 本地轻量模型（一次性投入）

| 工具 | 特点 | 硬件要求 | 适用 |
|------|------|---------|------|
| **Stable Video Diffusion** | 开源，图片→视频 | 8GB+显存 | 本地批量 |
| **AnimateDiff** | 轻量动画 | 4GB+显存 | 简单动画 |
| **Wav2Lip** | 口型同步 | CPU即可 | 配音视频 |
| **SadTalker** | 照片说话 | 4GB+显存 | 数字人 |

**优势**: 无API费用，隐私安全
**劣势**: 需要GPU，质量不如云端

---

### 方案3: 自动化脚本（最低成本）

**技术栈**:
- **FFmpeg** - 视频处理（免费）
- **MoviePy** - Python视频编辑（免费）
- **Pillow** - 图片处理（免费）
- **gTTS** - 文字转语音（免费）

**工作流**:
```
文本/数据 → Python脚本 → 自动生成视频
```

**优势**: 完全免费，批量处理
**劣势**: 需要素材，创意有限

---

## 推荐方案: 混合模式

### 场景1: 高质量宣传视频
```
脚本 → Sora/Runway生成素材 → 人工精剪
成本: 中等 | 质量: 高 | 算力: 低
```

### 场景2: 批量口播视频
```
文案 → HeyGen数字人 → 批量生成
成本: 低 | 质量: 中 | 算力: 零
```

### 场景3: 数据可视化视频
```
数据 → Python自动化 → FFmpeg合成
成本: 零 | 质量: 中 | 算力: 中
```

### 第一步: 选择工具

### 第二步: 搭建自动化流程
```python
# 示例：批量生成口播视频
import requests

def generate_video(script, avatar_id):
    """调用HeyGen API生成视频"""
    response = requests.post(
        "https://api.heygen.com/v2/video/generate",
        json={
            "script": script,
            "avatar_id": avatar_id,
            "voice_id": "zh-CN"
        }
    )
    return response.json()["video_url"]

# 批量生成
scripts = ["文案1", "文案2", "文案3"]
for script in scripts:
    video_url = generate_video(script, "avatar_001")
    print(f"视频生成: {video_url}")
```
