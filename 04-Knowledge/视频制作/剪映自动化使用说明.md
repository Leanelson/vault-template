# 剪映自动化系统 - 使用说明

## 🎯 系统介绍

完全免费的短视频批量生产系统，利用剪映免费版实现零成本视频制作。

---

## 📁 文件说明

| 文件 | 功能 |
|------|------|
| `剪映自动化脚本.py` | 主程序，批量生成视频 |
| `剪映坐标获取工具.py` | 配置工具，获取屏幕坐标 |
| `capcut_positions.json` | 坐标配置文件（生成后）|

---

## 🚀 快速开始

### 第一步：安装依赖

```bash
pip install pyautogui
```

### 第二步：配置坐标

由于每个人的屏幕分辨率不同，需要先获取剪映各按钮的坐标。

```bash
python 剪映坐标获取工具.py
```

按提示操作：
1. 选择"1. 记录坐标"
2. 将鼠标依次移到剪映各按钮位置
3. 按回车记录坐标
4. 生成 `capcut_positions.json`

### 第三步：运行自动化

```bash
python 剪映自动化脚本.py
```

## ⚙️ 配置说明

编辑 `剪映自动化脚本.py` 中的 CONFIG：

```python
CONFIG = {
    "capcut_path": "C:\\Program Files\\CapCut\\CapCut.exe",  # 剪映安装路径
    "template_name": "口播模板",  # 使用的模板名称
    "output_folder": "C:\\Users\\USER867114\\Videos\\剪映输出",
    "wait_time": {
        "open": 5,      # 打开剪映等待时间（秒）
        "load": 3,      # 加载模板等待时间
        "render": 60,   # 渲染等待时间（根据视频长度调整）
    }
}
```

## ⚠️ 注意事项

### 安全提示
1. **鼠标移左上角**: 紧急停止（PyAutoGUI安全机制）
2. **不要操作电脑**: 运行时请勿手动操作鼠标键盘
3. **先测试**: 首次使用请先测试1个视频

### 常见问题

**Q: 坐标不准确怎么办？**
A: 重新运行 `剪映坐标获取工具.py` 获取准确坐标

**Q: 剪映版本不同怎么办？**
A: 界面可能略有不同，需要重新获取坐标

**Q: 渲染时间不够怎么办？**
A: 调整 `CONFIG["wait_time"]["render"]`，根据视频长度设置

**Q: 如何批量替换更多元素？**
A: 修改 `replace_text()` 方法，添加更多替换逻辑

## 🔧 故障排除

### 问题1: 剪映无法打开
**解决**: 检查 `capcut_path` 配置是否正确

### 问题2: 点击位置错误
**解决**: 重新运行坐标获取工具

### 问题3: 渲染失败
**解决**: 增加 `wait_time["render"]` 时间

### 问题4: 文案输入乱码
**解决**: 确保文件编码为UTF-8
