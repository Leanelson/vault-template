# 国内AI视频制作方案研究报告

## 研究目标
找到国内可用的、省算力的视频制作方案

---

## 国内主流AI视频工具

### 1. 剪映（字节跳动）⭐推荐
- **官网**: https://www.capcut.cn
- **功能**: AI文案、AI配音、智能字幕、视频模板
- **成本**: 免费版够用，VIP ¥198/年
- **特点**: 
  - 国内访问快
  - 模板丰富
  - 支持批量处理
  - 手机/电脑端都有
- **API**: 暂无官方API，可用自动化脚本控制

### 2. 度加剪辑（百度）
- **官网**: https://ducut.baidu.com
- **功能**: AI写文案、AI配音、智能包装
- **成本**: 免费额度+会员
- **特点**: 与百度AI生态打通

### 3. 腾讯智影
- **官网**: https://zenvideo.qq.com
- **功能**: 数字人、文本配音、视频剪辑
- **成本**: 免费额度+按量付费
- **特点**: 
  - 2D/3D数字人
  - 多语种配音
  - 云端渲染

### 4. 阿里云视频智能
- **产品**: 视频生产、视频理解、视频搜索
- **官网**: https://www.aliyun.com/product/video
- **成本**: 按量付费
- **特点**: 企业级，有API

### 5. 讯飞智作
- **官网**: https://www.xfzhizuo.cn
- **功能**: AI配音、虚拟主播、视频制作
- **成本**: 按分钟计费
- **特点**: 语音技术强

### 6. 商汤如影
- **官网**: https://senseavatar.sensetime.com
- **功能**: AI数字人
- **成本**: 企业定制
- **特点**: 2D/3D数字人，效果逼真

### 7. 小冰数字人
- **官网**: https://www.xiaoice.com
- **功能**: 数字员工、视频生成
- **成本**: 企业定制
- **特点**: 情感计算，交互自然

### 8. 即梦AI（字节）⭐新增
- **官网**: https://jimeng.jianying.com
- **功能**: AI生图、AI生视频、智能画布
- **成本**: 免费额度+会员（¥30/月）
- **特点**: 
  - 与剪映深度打通
  - 文生视频、图生视频
  - 视频风格化
  - 每日免费积分
- **API**: 暂无公开API

### 9. 扣子（Coze）⭐新增
- **官网**: https://www.coze.cn
- **功能**: AI Bot开发、工作流编排、插件生态
- **成本**: 免费额度+按量付费
- **特点**: 
  - 可视化工作流
  - 丰富的插件（视频、图像、语音）
  - 可发布到抖音、飞书、微信
  - 支持知识库
- **API**: 有API，可集成

## 即梦 + 扣子 组合方案

### 方案：AI视频全自动工作流

```
扣子工作流:
  输入文案 → 即梦生成视频素材 → 剪映模板合成 → 导出成品
```

**扣子工作流配置**:
1. 触发器：接收文案/主题
2. 节点1：调用即梦插件生成视频片段
3. 节点2：调用剪映API（如有）或生成剪映工程文件
4. 节点3：输出成品视频链接

**优势**:
- 完全自动化
- 零代码
- 可视化编排
- 可定时批量执行

```
文案 → 剪映模板 → 批量生成 → 导出视频
```

- **质量**: 中上
- **批量**: 支持

### 方案B: 腾讯智影API
```python
# 调用腾讯智影API
import requests

def create_digital_human_video(text, avatar_id):
    response = requests.post(
        "https://api.zenvideo.qq.com/v1/video/create",
        json={
            "text": text,
            "avatar_id": avatar_id,
            "voice": "zh-CN-Xiaoxiao"
        },
        headers={"Authorization": "Bearer YOUR_TOKEN"}
    )
    return response.json()
```
- **本地算力**: 零
- **成本**: ¥0.5-2/分钟
- **质量**: 高
- **批量**: API支持
