# 自律箴言

> 原文来源：2026-06-06 飞书消息整理
> 用途：自我监督，时刻对照

---

## 原文

父母弱，你就学做生意，改变命运。父母强，你就发愤努力，入仕为官。家族强盛，你就利用家族的威望在本地发展。家境贫寒，唯一的出路就是远走他乡，谋求出路。辈辈开荒，不如十年寒窗。十年寒窗，不如三代经商。三代经商，抵不过祖上扛枪。祖上扛枪，也没有乌纱帽享。记住，只做三件事情，学习、赚钱、锻炼。只看三类书，历史、商道、营销。只交三类人。有能力、有想法、有执行力。想想要吃肉先喂猪，想要当官先读书，想要强大必须出丑。人不出丑，一直是狗，人一出丑，精神抖擞，出丑的越多，成长的越快。装三分痴呆防死，留七分正经谋生。遇到女人啊，一律就说她瘦了。遇到穷人，一律就说钱不重要，开心就好。遇到病人，就夸气色好，很快就会康复了。烟搭桥，酒铺路，关系带你上高速。这是缺一不可的成功三要素。送礼要提前送、向上送，而且是晚上送。改变命运的法宝。送礼、听话、感恩、分钱、融入团体、搞关系就是吃喝玩乐、送礼就是投其所所好。人情世故就是礼尚往来，人际关系就是合作愉快，这个就是人生。

## 核心提炼

### 背景判断力

根据自身条件选择合适的路径：

| 条件 | 路径 |
|------|------|
| 父母弱 | 学做生意，改变命运 |
| 父母强 | 发愤努力，入仕为官 |
| 家族强盛 | 利用家族威望在本地发展 |
| 家境贫寒 | 远走他乡，谋求出路 |

### 三件事

- 学习
- 赚钱
- 锻炼

### 三类书

- 历史
- 商道
- 营销

### 三类人

- 有能力
- 有想法
- 有执行力

### 成长心法

> 人不出丑，一直是狗。人一出丑，精神抖擞，出丑的越多，成长的越快。

- 装三分痴呆防死，留七分正经谋生
- 敢于出丑，敢于尝试

### 社交处世

- 遇到女人 → 夸她瘦了
- 遇到穷人 → 说钱不重要，开心就好
- 遇到病人 → 夸气色好，很快康复

### 成功三要素

**烟搭桥，酒铺路，关系带你上高速。**

- 送礼要提前送、向上送、晚上送
- 听话、感恩、分钱
- 融入团体、搞关系 = 吃喝玩乐 + 投其所好

### 核心逻辑

> 普通人翻身的路径：**学习 → 赚钱 → 混圈子**
> 其中「混关系」是加速器

- 人情世故 = 礼尚往来
- 人际关系 = 合作愉快
