# 🔍 快速搜索

> 库内常用搜索方式与关键词速查

## ⌨️ 检索方式

| 方式 | 操作 | 适用场景 |
|------|------|----------|
| 全局搜索 | `Ctrl/Cmd + Shift + F` | 全文关键词 |
| 快速切换 | `Ctrl/Cmd + O` | 按笔记名跳转 |
| 标签搜索 | 搜索框输入 `tag:#📂-project` | 按标签筛选 |
| 路径搜索 | 输入 `path:01-Projects/` | 限定目录 |
| 属性搜索 | 输入 `[status:🔄in-progress]` | 按 frontmatter 字段 |

## 🏷️ 常用标签

| 标签 | 含义 |
|------|------|
| `#📂-project` | 项目笔记 |
| `#✅-task` / `#✅-tasks` | 任务 |
| `#📝-meeting` | 会议纪要 |
| `#📚-knowledge` | 知识沉淀 |
| `#🤖-agent` | Agent 相关工作记录 |
| `#📋-template` | 模板 |

## 🔎 常用查询

```dataview
TABLE status, owner
FROM "01-Projects"
WHERE type = "project"
SORT file.mtime DESC
```

