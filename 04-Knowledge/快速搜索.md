## ⌨️ 检索方式

| 方式 | 操作 | 适用场景 |
|------|------|----------|
| 全局搜索 | `Ctrl/Cmd + Shift + F` | 全文关键词 |
| 快速切换 | `Ctrl/Cmd + O` | 按笔记名跳转 |
| 标签搜索 | 搜索框输入 `tag:#📂-project` | 按标签筛选 |
| 路径搜索 | 输入 `path:01-Projects/` | 限定目录 |
| 属性搜索 | 输入 `[status:🔄in-progress]` | 按 frontmatter 字段 |

## 🔑 Dataview 查询示例

在 Obsidian 中可以使用 Dataview 查询：

```dataview
TABLE file.link as "笔记", file.ctime as "创建时间"
FROM ""
WHERE contains(file.tags, "project")
SORT file.ctime DESC
```

```dataview
LIST FROM ""
WHERE type = "task" AND status = "🔄in-progress"
```

## 🔎 常用查询

```dataview
TABLE status, owner
FROM "01-Projects"
WHERE type = "project"
```

```dataview
TASK
```

## 💡 搜索技巧

1. **Ctrl/Cmd + K** — 快速搜索（Obsidian 内置）
2. **Ctrl/Cmd + O** — 快速切换文件
3. **标签搜索** — 使用 `#tagname` 搜索同一标签的笔记
4. **Dataview** — 复杂查询（需要安装 Dataview 插件）
