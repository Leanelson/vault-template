## 🏷️ 状态标签

| 标签 | 含义 |
|------|------|
| `🔴 高优先级` | 需要立即处理 |
| `🟡 中优先级` | 计划内处理 |
| `🟢 低优先级` | 有空再做 |
| `🔄 进行中` | 正在处理 |
| `✅ 已完成` | 任务完成 |
| `⏳ 等待中` | 等待外部响应 |
| `❌ 阻塞` | 被阻塞无法推进 |
