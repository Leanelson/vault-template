## 一、最重要的结论：域名链路

```
浏览器 https://www.zlh1.com
  → DNS 192.144.234.183
  → VPS nginx :443  /etc/nginx/sites-available/frp.zlh1.com（certbot 管理的那个 server 块）
  → VPS 127.0.0.1:8080   frps 的 vhost_http_port
  → frpc [zlh-web-vhost] type="http" customDomains=["www.zlh1.com","zlh1.com"]
  → 本机 127.0.0.1:9500  systemd --user zlh-website
  → /home/ctyun/zlh1/website/   backend-vps.py 提供静态 + /api/*
```

**并行备用通路（不能动）：** nginx 默认 server `conf.d/website.conf`（:80，`server_name _`）
→ 127.0.0.1:9500。承载裸 IP 访问和**节点3 每 3 分钟拉取的 `/n3k7/agent.ps1` 自愈脚本**。

### 历史 404 的真正原因（已修复）

`www.zlh1.com` 曾返回 frp 自带的 "powered by frp" 404 页。
根因：nginx 把域名转给 8080，但本机 `~/.config/frp/dsh-web.toml` 里**只有 `type="tcp"` 的
`zhongliheng-web`，没有任何 `type="http"` 代理**，于是 frps 上不存在匹配该域名的虚拟主机。
修法：补回 `[[proxies]] name="zlh-web-vhost" type="http" localPort=9500 customDomains=[...]`。

### 关键事实：到底哪个目录在对外服务

本机存在**两份内容相同的站点**，容易搞错：

| 目录 | 端口 | 是否在域名链路上 |
|---|---|---|
| `/home/ctyun/zlh1/website/` | 9500（backend-vps.py） | ✅ **是**（并含 `n3k7/`） |
| `/home/ctyun/stepclaw-site/website/` | 9000（`python -m http.server`） | ❌ 不是 |

**验证方法（可复用）：** 往两个目录各放一个探针文件，用公网 URL 请求 —— 只有
`zlh1/website/` 的那个返回 200。

## 七、可复用的踩坑记录

1. **nginx 1.24 不支持 `http2 on;`**（1.25+ 才有），必须写 `listen 443 ssl http2;`。
2. **Let's Encrypt 已停发 OCSP**，配 `ssl_stapling on` 只会让 `nginx -t` 报无意义警告。
3. **certbot `renew --dry-run` 自带最长 ~8 分钟随机延迟**，短超时会误判为卡死；日志里会写
   `Non-interactive renewal: random delay of N seconds`。
4. **headless Chrome 有 490px 最小视口**，`--window-size=390` 无效。
   测真实窄屏要用 `<iframe width="390">` 套本地 http 服务。
5. **`body { overflow-x: hidden }` 会裁剪 overflow 但不会扩大可滚动区** —— 
   判断"是否真的能横向滑动"要 `scrollX`，不能只看 `scrollWidth`。
6. **用脚本批量改中文引号时，必须先保护 `<head>` 整块**：favicon 的 data-URI 里含
   `<svg ...>`，会被"按标签切分"的逻辑搞坏，把属性闭合引号也转成中文引号。
   正确做法是分两遍：先按"左右方向"归一化 `“”`，再处理纯 ASCII 直引号补转换。
7. **`Select-String -SimpleMatch` 会把 `|` 当字面量**，导致多关键词搜索假阴性（Windows 侧）。
8. **节点2/节点3 的中文经 WinRM/SSH 回传会乱码**，需先设
   `[Console]::OutputEncoding=[Text.Encoding]::UTF8`；PowerShell 用 `-EncodedCommand`（UTF-16LE base64）。
9. **写文件前若被 `edit` 拒绝**（"file changed since it was read"），重新 `read` 一次即可。
