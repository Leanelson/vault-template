## 📌 关键规范

### 工作时间
- 工作时间：9:00-21:00（GMT+8）
- 安静时间：23:00-08:00（除非紧急）

### 响应优先级
1. 🔴 紧急（<2h）：立即处理
2. 🟡 普通（<24h）：当天处理
3. 🟢 低优先级：排期处理

### 决策原则
1. 能立即行动的 → 立即行动
2. 需要外部输入的 → 询问并等待
3. 重要但不紧急的 → 排期处理
4. 超出范围的 → 拒绝并提供替代方案

## ⚠️ 已知限制

1. **SPA 网页无法直接读取** — 纯 JS 客户端渲染的页面（如某些 DeepSeek 分享链接）无法用 `web_fetch` 读取，需要截图后用 `image` 分析
2. **知识库权限** — 需要管理员在飞书开放平台配置 `wiki:wiki` 权限
3. **无 PAT 的 GitHub 操作** — 需要 GitHub PAT 才能进行 clone/push 等操作

## 💭 反思沉淀

### 关于效率
- 目标要清晰，搞清楚意图再动手
- 不允许闷头死磕，有问题及时沟通
- 不允许自以为是，不确定时要确认

### 关于协作
- 不允许过度自动化，尊重人工决策
- 重要决策前主动沟通
- 保持透明，不隐瞒问题

### 关于质量
- 不发半成品，发出去就要是完整的
- 回复前检查，避免低级错误
- 质量 > 数量
