# 扣子（Coze）视频生成工作流搭建指南

## 准备工作

### 1. 注册/登录扣子
- 访问: https://www.coze.cn
- 点击"开始使用"
- 使用抖音账号或手机号登录

### 2. 准备素材
- 视频文案（可AI生成）
- 背景音乐（可选）
- 视频模板（剪映）

---

## 工作流设计

### 目标
创建一个全自动视频生成Bot：
```
输入主题 → AI写文案 → 即梦生成视频 → 剪映合成 → 输出成品
```

---

## 步骤一：创建Bot

### 1. 进入扣子工作台
- 登录后点击左侧"Bots"
- 点击"创建Bot"

### 2. 填写Bot信息
```
名称: 视频生成助手
描述: 输入主题，自动生成视频
图标: 上传或使用AI生成
```

### 3. 选择模型
- 推荐: "豆包大模型" 或 "GPT-4"
- 开启"长上下文"（如需处理长文案）

---

## 步骤二：配置工作流

### 1. 进入工作流编辑
- 点击Bot左侧"工作流"
- 点击"创建工作流"

### 2. 设计工作流节点

#### 节点1: 开始节点
```
输入参数:
  - topic (string): 视频主题
  - style (string): 视频风格（可选）
```

#### 节点2: 大模型节点（写文案）
```
系统提示词:
  你是一位专业的短视频文案写手。
  根据用户提供的主题，写一段30秒短视频的口播文案。
  要求：口语化、有吸引力、适合AI配音。

输入:
  - topic: {{开始.topic}}

输出:
  - script: 生成的文案
```

#### 节点3: 即梦AI插件（生成视频）
```
插件: 即梦AI
操作: 文生视频

输入:
  - prompt: {{大模型.script}}
  - duration: 4  # 4秒视频
  - ratio: "9:16"  # 竖屏

输出:
  - video_url: 生成的视频URL
```

#### 节点4: 讯飞智作插件（AI配音）
```
插件: 讯飞智作
操作: 文本转语音

输入:
  - text: {{大模型.script}}
  - voice: "zh-CN-Xiaoxiao"  # 女声
  - speed: 1.0

输出:
  - audio_url: 配音文件URL
```

#### 节点5: 剪映合成（需API或手动）
```
由于剪映暂无公开API，此步骤可:
选项A: 生成剪映工程文件下载
选项B: 输出视频+配音，用户手动合成
选项C: 使用其他视频编辑API
```

#### 节点6: 结束节点
```
输出:
  - video_url: {{即梦AI.video_url}}
  - audio_url: {{讯飞智作.audio_url}}
  - script: {{大模型.script}}
  - message: "视频生成完成！请下载视频和配音，在剪映中合成。"
```

---

## 步骤三：配置触发器

### 方式1: 对话触发
- 用户输入: "生成一个关于{主题}的视频"
- Bot自动调用工作流

### 方式2: 定时触发（批量）
```
设置定时任务:
  - 每天早上9点
  - 从数据库读取今日主题
  - 批量生成视频
```

### 方式3: Webhook触发
```python
# 外部系统调用
import requests

requests.post(
    "https://api.coze.cn/webhook/YOUR_BOT",
    json={"topic": "AI发展趋势"}
)
```

## 步骤四：发布Bot

### 1. 测试Bot
- 在扣子平台测试对话
- 验证工作流执行

### 2. 发布渠道
- 抖音: 发布到抖音评论区

- 微信: 公众号/客服接入

## 优化建议
