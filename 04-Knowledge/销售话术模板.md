# 具体联系话术模板

> 各行业客户联系话术，复制即可使用

---

## 一、开场白模板

### 加油站开场白
```
您好，我是西安众力恒商贸的XX，随行付官方合作伙伴、小精灵/智百威授权代理商。
我们专门为加油站提供油品管理、会员储值、非油品销售一体化系统，服务过10000+商户。
想了解您加油站是否有系统升级或新系统需求？
```

### 餐饮开场白
```
您好，我是西安众力恒商贸的XX，专业做餐饮外卖收银系统。
支持美团、饿了么、抖音团购对接，会员管理、后厨打印一体化。
想了解一下您这边餐厅现在用的是什么系统，有什么可以帮到您的？
```

### 超市开场白
```
您好，我是西安众力恒商贸的XX，做超市、便利店收银系统。
我们有进销存管理、会员储值、供应链管理，适合各种规模的超市便利店。
想了解一下您这边有什么需求？
```

---

## 二、客户需求挖掘

### 探测需求
- "您现在用的系统用了多久了？"
- "平时用起来顺手吗？有没有不方便的地方？"
- "现在一个月流水大概多少？"

### 痛点提问
- "系统卡顿不卡顿？"
- "库存对不上的时候多不多？"
- "会员积分怎么管理的？"

---

## 三、跟进话术

### 已联系客户
```
您好，XX总，上次跟您聊过关于系统的事，想问问您这边考虑得怎么样了？
我们最近有个活动，XXX天内付款可以优惠XXX。
您什么时候方便，我带资料过去给您演示一下？
```

### 无人接听
发短信：
```
您好，我是西安众力恒商贸的XX，关于加油站/餐饮/超市系统升级方案，方便时回个电话：XXX。
```

---

## 四、注意事项

1. 不要一上来就报价，先了解需求
2. 不要贬低竞争对手
3. 记录每次沟通内容到客户跟进表
4. 3天内必须跟进一次
