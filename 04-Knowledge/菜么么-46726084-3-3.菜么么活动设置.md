# 3-3.菜么么活动设置

参数设置不管什么活动，系统参数中有四个总的开关是否启用活动是代表前台是否开启活动线上堂食、外带、外卖都是对应的参数活动设置注意：并不是所有活动都支持线上，设置前请确认好（标注支持线上的才能在线上使用）
