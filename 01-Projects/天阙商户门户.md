# 天阙商户门户

> 商户入网系统，接入天阙支付平台 API

## 📋 项目概述

- **路径：** `~/.openclaw/workspace/projects/tianque-merchant-portal/`
- **技术栈：** Next.js + TypeScript + SQLite
- **状态：** 进行中（约 745 行代码）
- **目标：** 商户自主入网 + 后台管理

## 🏗️ 功能模块

### 1. 商户入网表单 `/`
- Step 1：法人信息（姓名、身份证、有效期、手机）
- Step 2：店铺信息（名称、地址、经营范围）
- Step 3：资质信息（营业执照、银联号）
- 自动生成密钥对（PKCS8 格式）

### 2. 商户后台 `/merchant/[id]`
- 查看配置
- 重置密钥对
- 修改密码

### 3. 管理后台 `/admin`
- 商户列表
- 需要 ADMIN_PASSWORD（环境变量配置）

## 🔌 API 对接

### 天阙 API 文档
- Swagger UI：https://paas.tianquetech.com/docs/#/api/tpzlsc1
- 接入指引：https://paas.tianquetech.com/docs/#/guide/jrlc

### 关键配置
| 项目 | 说明 |
|------|------|
| 私钥格式 | PKCS8（`BEGIN PRIVATE KEY`，不含 RSA） |
| amt 格式 | 字符串 `"0.01"`，不是数字 |
| 签名算法 | SHA1，不是 SHA256 |
| reqData 顺序 | 必须与代码定义顺序一致，不按字母排序 |

## 🗄️ 数据库

- SQLite：`merchant.db`
- 表：`merchants`（商户信息）、`logs`（操作日志）
