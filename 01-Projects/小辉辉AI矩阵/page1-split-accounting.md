# 随行付分账业务

## 一、业务介绍

### 什么是分账？

分账，是指在一个交易订单完成后，平台方根据预设规则，将交易资金自动分配给多个参与方的资金结算模式。随行付分账业务，是基于持牌支付机构资质，为平台型企业提供的**合规、安全、高效**的资金分账解决方案。

> **核心优势**：资金由持牌支付机构全程监管，平台不触碰资金，彻底规避"二清"风险。

### 为什么选择随行付分账？

| 对比维度 | 传统分账模式 | 随行付分账方案 |
|---------|------------|--------------|
| 合规性 | 平台自有资金池，存在二清风险 | 持牌机构资金监管，100%合规 |
| 结算效率 | T+1或更长 | 实时分账，秒级到账 |
| 手续费 | 多方多次扣费，成本高 | 统一费率，成本降低30%+ |
| 对账难度 | 人工核对，易出错 | 系统自动对账，差错率<0.01% |
| 扩展性 | 分账方数量有限 | 支持最多50个分账方 |

## 二、核心功能

### 1. 自动分账 — 智能规则引擎

**功能亮点**：
- **比例分账**：按固定百分比自动分配（如平台抽成20%，商家得80%）
- **固定金额**：每笔订单扣除固定服务费后，剩余归商家
- **阶梯分账**：根据订单金额区间设置不同分账比例
- **混合模式**：比例+固定金额组合，满足复杂业务场景

**技术参数**：
| 指标 | 参数 |
|-----|------|
| 单笔分账参与方 | 最多50个 |
| 分账延迟 | < 500ms |
| 日分账笔数上限 | 100万笔 |
| 成功率 | 99.99% |

### 2. 多方结算 — 一站式资金归集

**支持场景**：
- **平台+商户**：电商平台与入驻商家的资金分配
- **品牌+门店**：连锁总部与各门店的收益分成
- **服务商+渠道**：服务商与下级渠道商的佣金结算
- **多方合作**：共享经济中车主、平台、保险公司的分润

**结算周期灵活配置**：
| 结算类型 | 到账时间 | 适用场景 |
|---------|---------|---------|
| D+0 | 实时到账 | 高频小额交易 |
| D+1 | 次日到账 | 日常经营结算 |
| T+1 | 工作日次日 | 大额资金结算 |
| 自定义 | 按周/按月 | 周期结算需求 |

### 3. 灵活比例 — 动态分账策略

**分账规则配置示例**：

```
场景：外卖平台订单分账
订单金额：¥100

分账方案：
├─ 平台服务费：10% → ¥10
├─ 配送费：固定¥5 → 骑手
├─ 商家实际收入：¥85
└─ 平台营销补贴：¥5（从平台服务费中扣除）
```

**高级功能**：
- **延迟分账**：支持7天、15天、30天无理由退款期后再分账
- **部分退款处理**：退款时自动按比例回滚各方资金
- **分账回退**：异常订单支持资金原路回退

## 三、适用场景

### 1. 电商平台

**痛点**：平台撮合交易后，需向众多商家分账，人工处理效率低、易出错。

**解决方案**：
- 买家支付后，系统自动按商品归属分账至各商家
- 平台服务费自动扣除
- 退款时自动回滚分账

**效果数据**：
| 指标 | 使用前 | 使用后 | 提升 |
|-----|-------|-------|------|
| 对账时间 | 3人×4小时/天 | 系统自动 | 节省12人时/天 |
| 差错率 | 0.5% | 0.01% | 降低98% |
| 商家满意度 | 72% | 96% | +24% |

### 2. 加盟连锁

**痛点**：总部需向各门店分润，财务工作量大，门店资金到账慢。

**解决方案**：
- 门店收款实时分账：总部抽成+门店收入同步到账
- 支持多级分账：品牌方→区域代理→门店
- 自动生成分润报表

**典型分账结构**：
```
顾客支付 ¥100
    ├─ 品牌管理费 5% → 总部 ¥5
    ├─ 区域代理费 3% → 代理商 ¥3
    └─ 门店收入 92% → 门店 ¥92
```

### 3. 共享经济

**痛点**：多方参与的交易（如网约车、短租），分账规则复杂，对账困难。

**解决方案**：
- 支持多方实时分账：车主/房东、平台、保险公司、政府税费
- 按订单维度精确分账
- 提供完整的资金流水凭证
