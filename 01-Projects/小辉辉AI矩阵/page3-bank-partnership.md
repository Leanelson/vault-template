# 随行付银行联合收单

## 一、业务介绍

### 什么是银行联合收单？

银行联合收单，是随行付与各大银行联合推出的**政策性补贴收单服务**。商户通过银行指定通道收款，可享受银行提供的费率补贴，实际支付费率远低于市场标准，部分商户甚至可以享受**零费率**。

### 政策背景

国家持续推进普惠金融政策，鼓励银行服务实体经济，降低小微企业经营成本。随行付作为持牌支付机构，与多家银行达成战略合作，将政策红利直达商户。

### 业务模式

```
┌─────────┐    支付    ┌─────────┐    清算    ┌─────────┐
│  消费者  │ ───────→ │ 随行付  │ ───────→ │  银行   │
│         │          │ (收单)   │          │ (结算)  │
└─────────┘          └─────────┘          └─────────┘
                            ↓
                       费率补贴
                            ↓
┌─────────┐          ┌─────────┐
│  商户   │ ←────────│  银行   │
│ (到账)  │   补贴后资金   │ (补贴)  │
└─────────┘          └─────────┘
```

### 核心优势

| 优势 | 说明 |
|-----|------|
| **费率超低** | 补贴后费率0%-0.25%，远低于市场标准 |
| **资金安全** | 银行直接清算，资金路径清晰 |
| **到账稳定** | 银行级系统，到账成功率99.9%+ |
| **政策合规** | 符合监管要求，长期稳定 |
| **服务专业** | 银行+随行付双重服务支持 |

## 二、费率补贴政策详解

### 补贴模式

| 模式 | 说明 | 适用对象 |
|-----|------|---------|
| **全额补贴** | 银行承担全部手续费，商户零成本 | 特定行业/活动期 |
| **差额补贴** | 银行补贴部分费率，商户承担剩余 | 一般商户 |
| **阶梯补贴** | 根据交易规模，补贴比例递增 | 大额商户 |
| **定向补贴** | 针对特定行业/区域的专项补贴 | 政策扶持行业 |

### 申请流程

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│  第一步  │ → │  第二步  │ → │  第三步  │ → │  第四步  │ → │  第五步  │
│ 资质准备 │   │ 银行开户 │   │ 提交申请 │   │ 审核签约 │   │ 设备部署 │
│  (1天)  │   │  (1-3天) │   │  (即时)  │   │ (1-2天)  │   │  (1-3天) │
└─────────┘   └─────────┘   └─────────┘   └─────────┘   └─────────┘
```

#### 详细步骤

**第一步：资质准备**
- [ ] 营业执照复印件（加盖公章）
- [ ] 法人身份证复印件
- [ ] 经营场所照片（门头+内部）
- [ ] 银行结算账户证明
- [ ] 特殊行业许可证（如有）

**第二步：银行开户/关联**
- [ ] 在目标银行开立结算账户
- [ ] 或关联已有银行账户
- [ ] 签署银行收单服务协议

**第三步：提交申请**
- [ ] 登录随行付官网/APP
- [ ] 选择"银行联合收单"入口
- [ ] 选择合作银行
- [ ] 上传资质材料
- [ ] 提交审核

**第四步：审核签约**
- [ ] 资质审核（1-2个工作日）
- [ ] 审核通过后签署电子协议
- [ ] 确认费率及补贴方案

**第五步：设备部署**
- [ ] 领取/购买收款设备
- [ ] 设备激活绑定
- [ ] 测试交易
- [ ] 正式启用

### 审核时效

|-----|------|

| 银行复审 | 1-2个工作日 |

## 六、常见问题

### Q1：银行联合收单和普通收单有什么区别？

| 对比项 | 银行联合收单 | 普通收单 |
|-------|------------|---------|
| 费率 | 0%-0.25% | 0.38%-0.60% |
| 资金清算 | 银行直接清算 | 支付机构清算 |
| 补贴来源 | 银行政策补贴 | 无 |
| 到账时效 | D+0 | D+0/D+1 |
| 申请门槛 | 需在银行开户 | 无特殊要求 |

### Q2：补贴是永久的吗？

补贴期限根据银行政策而定：
- **长期补贴**：三农、医疗等政策性行业
- **限期补贴**：一般1-3年，到期可续签
- **活动补贴**：特定时期（如开业季、双十一）

### Q3：可以同时申请多家银行的联合收单吗？

可以。商户可根据不同门店位置、客群特征，选择不同的合作银行，实现费率最优化。

### Q4：补贴如何发放？

| 发放方式 | 说明 |
|---------|------|
| 实时抵扣 | 交易时直接按补贴后费率扣费 |
| 月度返还 | 次月返还上月补贴金额至结算账户 |
| 季度返还 | 季度末返还本季度补贴 |
