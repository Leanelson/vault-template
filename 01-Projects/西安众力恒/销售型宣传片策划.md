# 西安众力恒商贸有限公司 - 销售型宣传片策划

## 目标受众
- 中小商户老板
- 加油站经营者
- 零售店/餐饮店负责人
- 想数字化转型的传统商家

## 核心痛点
1. 收款不方便，费率太高
2. 会员管理混乱，回头客少
3. 库存不清楚，经常断货或积压
4. 没有线上渠道，客流单一
5. 数据不会看，经营靠感觉

## 移动端优化要点

### 视觉设计
- 竖屏优先（9:16比例）
- 大字体，清晰可读
- 高对比度配色
- 单屏只展示1个重点

### 交互设计
- 自动播放，无需点击
- 支持手势滑动切换
- 底部固定联系按钮
- 一键拨打电话/加微信

### 内容节奏
- 每幕不超过15秒
- 关键信息重复3次
- 电话号码始终可见
- 紧迫感营造（限时优惠）

## 技术实现方案

### 方案A：HTML5竖屏视频（推荐）
- 9:16比例，适配手机
- CSS动画 + JavaScript
- 自动播放，循环播放
- 底部固定联系栏

### 方案B：真实视频拍摄
- 实地拍摄客户案例
- 真人出镜讲解
- 后期剪辑配音
- 需要专业设备

### 方案C：AI生成视频
- 使用即梦/剪映AI生成
- 数字人讲解
- 素材库拼接
- 成本较低

## 执行计划
